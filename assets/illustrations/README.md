# assets/illustrations/ · 上线插画资源目录

本目录存放**上线插画资源**（手绘 / 外采产出的 PNG）。

## 双层风格映射（PRD v0.6 §3.2）

| 位置 | 尺寸 | 风格 |
|---|---|---|
| 首页空状态 / 纪念日 / 心愿反馈 / 绑定页 | ≥200px | **油画厚涂**（手绘/外采） |
| 心情脸谱 / 天气 / 经期图章 / 心愿分类 / 按钮装饰 | <100px | **几何极简**（SVG/简单线条） |

## 硬约束

- **来源登记**：每张插画必须先登记 `SOURCES.md`（本人手绘 / 授权素材），无来源记录不得入库（PRD §6.4 / P2-01）
- 单文件 ≤ 50KB；字体 ≤ 100KB；必须本地打包，禁止网络图
- 禁止 AI 生成图（含 AI 平台水印）

## 命名规范

`{页面}_{用途}.png`，示例：`home_empty.png`、`mood_happy.png`、`weather_sunny.png`、`anniversary.png`
