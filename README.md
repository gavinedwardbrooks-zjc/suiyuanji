# 碎愿集 · Suiyuanji

一个给两个人用的小工具：一个人愿意写下今天，另一个人愿意打开看看。

没有广告，没有推荐流，没有第三人。只有你们两个人的日子，被安静地收在一起。

---

## 关于碎愿集

碎愿集是一个自用的小程序，现在开源出来。它想解决的问题很朴素 ——

日子过得很快，很多值得记住的小事（今天很想吃的一碗面、下班路上突然变好的心情、
一句没来得及说的话）如果不写下来，过两周就没了。但大多数记录工具都太「工具」了：
要么是效率软件，要么是公开的社交平台。碎愿集想做的，是一个**只属于两个人的角落**。

所以它有几条不动摇的设定：

- **不打扰**。没有推送轰炸，没有签到压力，没有连续记录天数的考核。想起来就写，忘了也没关系。
- **不公开**。所有内容都在**你自己部署的**微信云开发环境里，没有第三方广告，也没有数据买卖。
- **有边界**。日记正文默认只有本人能看；想把某一天给 TA 看，需要你亲手打开那一天的分享。
- **不假装热闹**。它不做广场、不做关注、不做排行榜。两个人用就够了。

## 在这里，可以记录什么

不按功能模块说，按一天里可能发生的片刻说：

**早上，给自己留一句。**
今天的心情、天气，生活 / 工作 / 成长三小段文字。这三段默认是私密的，写完只属于你。
如果你愿意，可以在日历里挑某一天单独分享给 TA —— 是逐天授权的，随时能收回。

**白天，记下想做的事。**
今天的目标（可以设一个提醒时间）、几件小事。有些事是你们两个人的 ——
共同待办单独存放，两个人都能添加、勾掉、删除，和各自的私人小事不混在一起。

**下午，读一会儿书。**
把手机里的 PDF 或 TXT 导进「纸间心事」，像书架一样摆着，读到哪页就记到哪页。

**晚上，看看对方。**
TA 今天给自己打了几分、有没有新心愿、有没有留一句悄悄话。
心愿是些很小的事 —— 想吃点什么、想去做点什么。

**偶尔，一起做个不用商量的决定。**
「今天吃什么」给出一个三菜组合，「今天去哪里」翻出一处地方。谁确认了，两个人的首页
就都会看到同一个结果，省掉一轮「随便」。

**还有一些琐碎但重要的事。**
在一起的纪念日、经期日历（默认只有本人可见，共享需要本人授权）、
每晚一句自动生成的小结（没配置 AI 服务时用内置模板兜底）。
关系变化了也不至于被困住：可以解绑、重新绑定，也可以删除数据、注销账号。

**桌面版（可选，Windows）**：一个小窗口贴在电脑边上，手机扫码确认后，
可以在电脑上读写今天的目标和小事，支持窗口透明度和置顶。
它只做这两件事，不替代手机端记日记。**当前状态：代码完整、本地测试通过，

## 如何体验

先说清楚：**仓库本身不提供可以直接扫码使用的版本。**
这里的 AppID 是占位符，云环境也需要你自己的 —— 想用碎愿集，需要自己部署一份。

如果你想自己跑一份：

1. 注册一个微信小程序，开通云开发，记下自己的 AppID 和环境 ID；
2. 用微信开发者工具导入本目录；
3. 生成本地私有配置（`config.js` 里只有占位符，真实配置不会入库）：

   ```bash
   node scripts/init-local-config.js
   ```

4. 在 `cloudfunctions/` 下逐个上传部署云函数（右键 →「上传并部署：云端安装依赖」）。

完整的部署清单（集合、索引、环境变量、定时触发器）在
[docs/DEPLOYMENT.md](./docs/DEPLOYMENT.md)，环境和常见报错在
[docs/DEVELOPMENT.md](./docs/DEVELOPMENT.md)。

> 如果将来有了正式发布的版本，这里会补上小程序码 —— 在此之前，不放任何二维码、
> 下载链接或「已发布」的说法。

## 项目状态

碎愿集是自用项目开源出来的，功能完整度和「能不能直接拿来用」是两件事，
这里分开写清楚。

| 部分 | 状态 |
|---|---|
| 微信小程序 + 11 个云函数 | 代码完整，本地 83 个测试文件全绿（全新克隆 82/83，见下）；据维护者说明已在自有云环境日常使用 |
| 桌面版客户端（Windows） | 代码完整，本地可运行；没有安装包，未做 Linux / 信创系统适配 |
| 桌面版依赖的 3 个云函数 | **从未部署过**。真实扫码登录、跨端同步等 6 项验收**全部未验证（UNVERIFIED）** |

补充两点：

- 全新克隆后 `tests/config-local.test.js` 会有一条失败，因为它校验的是一份被
  `.gitignore` 排除的本地内部报告，仓库里没有这个文件。其余测试应当全绿。
  原因见 [docs/DEVELOPMENT.md](./docs/DEVELOPMENT.md)。
- 桌面版登录用的公开接口目前**没有速率限制**，正式对外前必须补上，已记在
  [SECURITY.md](./SECURITY.md) 与 [docs/DESKTOP_HANDOVER.md](./docs/DESKTOP_HANDOVER.md)。

桌面版的完整现状（扫码协议、冻结基线、恢复开发的步骤）见
[docs/DESKTOP_HANDOVER.md](./docs/DESKTOP_HANDOVER.md)。**「本地可用」不等于「生产可用」。**

## 一起让碎愿集变得更好

碎愿集是业余时间做的小项目，很欢迎别人一起补。能做的事很多，不一定都要写代码：

- 发现哪里用起来别扭、文案生硬、空状态让人不知所措 —— 开个 Issue 说说；
- 想加一个功能，先开 Issue 聊，避免写完发现方向不对；
- 代码贡献看 [CONTRIBUTING.md](./CONTRIBUTING.md)（分支、提交、测试门槛、文档同步要求）；
- 安全相关问题**不要**开公开 Issue，走 [SECURITY.md](./SECURITY.md) 里的私下渠道。

提 PR 前请记得：不要在仓库里提交任何私有配置、真实环境 ID、真实用户数据。
